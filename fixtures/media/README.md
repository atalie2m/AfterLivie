# Media Fixtures

Binary media samples are intentionally not committed yet. Add only small, redistributable
fixtures here and keep generated exports out of git.

Required v1.0 fixture classes:

- MP4 H.264 AAC 720p
- MOV H.264 AAC 1080p
- MP4 with no audio
- rotation metadata sample
- VFR sample if legally available
- unsupported/problematic source for diagnostics
